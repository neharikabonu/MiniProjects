# Calculator 📱

A simple and interactive calculator built using **HTML, CSS, and JavaScript**. This project was created to practice JavaScript fundamentals, DOM manipulation, event handling, and application logic.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage calculations
- Decimal number support
- `00` and `0` input
- Clear (`AC`) functionality
- Delete (`⌫`) functionality
- Division-by-zero error handling
- Consecutive calculations
- Keyboard support
- Interactive button hover and click effects

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling, layout, and visual effects
- **JavaScript** – Calculator logic and user interactions

## 📚 JavaScript Concepts Practiced

- DOM Selection
- Event Listeners
- Event Delegation
- `event.target`
- `classList.contains()`
- `textContent`
- `forEach()`
- Functions
- `switch` statements
- Conditional Statements
- Variables and application state
- Keyboard Events
- Programmatic `.click()`
- String methods such as `slice()`
- Number conversion
- Input validation

## ⌨️ Keyboard Controls

| Key | Action |
|---|---|
| `0 - 9` | Enter numbers |
| `.` | Enter decimal |
| `+` | Addition |
| `-` | Subtraction |
| `*` / `x` | Multiplication |
| `/` | Division |
| `%` | Percentage |
| `Enter` / `=` | Calculate result |
| `Backspace` | Delete last character |
| `Escape` | Clear calculator |

## 🧠 What I Learned

This project helped me understand how HTML, CSS, and JavaScript work together to create an interactive web application.

Through this project, I practiced handling user interactions, working with DOM elements, maintaining application state, performing calculations using reusable functions, and handling both mouse and keyboard inputs.

I also learned how event delegation can be used to efficiently handle multiple buttons using a single event listener.
