# Student Management System

A simple console-based **Student Management System** built using **Java**. This project demonstrates the fundamentals of Object-Oriented Programming (OOP), CRUD operations, and the Java Collections Framework.

## Features

* Add a new student
* View all students
* Search a student by ID
* Update student details
* Delete a student
* Prevent duplicate student IDs
* Menu-driven console interface

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList (Java Collections Framework)
* Scanner (User Input)

## Project Structure

```
StudentManagementSystem/
│
├── Main.java
├── Student.java
└── StudentManagement.java
```

### File Description

* **Main.java** – Handles the menu, user input, and program flow.
* **Student.java** – Represents a student object with fields, constructor, getters, setters, and `toString()`.
* **StudentManagement.java** – Contains the business logic for managing student records.

## Learning Outcome

This project was built to strengthen core Java programming skills by applying Object-Oriented Programming concepts in a real-world CRUD application. It demonstrates how to organize code into multiple classes, manage data using `ArrayList`, validate user input, and design a clean, menu-driven console application.
