# Personal Portfolio Website

A simple and responsive personal portfolio website built using HTML and CSS. This project showcases my profile, skills, education, and projects in a clean and user-friendly layout.

## Features

- Responsive design
- Sidebar with personal information
- About Me section
- Skills section
- Education section
- Portfolio section
- Social media links
- Hover effects and smooth transitions

## Technologies Used

- HTML5
- CSS3
